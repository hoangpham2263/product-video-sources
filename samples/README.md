# Samples

Previews for the Product Video app's **Hiệu ứng** and **Góc máy** pages, all made from one dining-table photo.

- `transitions/<name>.mp4`: every ffmpeg `xfade` transition the app can use (384x584, 0.8 s transition), from the same two shots.
- `angles/<id>.jpg`: every angle of the app's `data/angles.json`, drawn by Codex CLI from the same product photo.

The app links to these files directly; they are not part of `manifest.json`.
